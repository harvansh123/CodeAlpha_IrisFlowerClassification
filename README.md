# Iris Flower Classification Using Machine Learning

## Project Overview

This project uses Machine Learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

## Dataset

The project uses the built-in Iris dataset from the Scikit-learn library. It contains 150 samples from three flower species.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Project Steps

1. Load the Iris dataset.
2. Explore and analyze the dataset.
3. Check missing values and statistical information.
4. Visualize flower measurements using a scatter plot.
5. Train a Random Forest classification model.
6. Evaluate the model using accuracy, a classification report, and a confusion matrix.
7. Predict the species of a new flower.

## Model Performance

The Random Forest model achieved **90% accuracy** on the test dataset.

## Sample Prediction

The model predicted the flower species as `setosa` for the sample measurements provided.

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells in order.
3. View the model results and sample prediction.
